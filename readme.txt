== Description ==

Keeps selected post types and taxonomies in sync, storing related IDs in post and term meta.

= Features =

TBA

= Installation =

1. Upload the plugin to `/wp-content/plugins/post-type-taxonmy-sync/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to Settings > Post/Tax Sync to configure

= Requirements =

* WordPress 5.7+
* PHP 8.2+
